# Security policy

## Supported versions

Only the current `main` branch and the live site it deploys,
<https://sstoehrm.github.io/stack-cap-bench/>. There are no releases; fixes
land on `main`. The vulnerability gate action in `.github/actions/vuln-gate`
is supported at the latest commit on `main`.

## Reporting a vulnerability

Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/sstoehrm/stack-cap-bench/security/advisories/new).
Please don't open a public issue.

This is a personal project, maintained on a best-effort basis: I aim to reply
within two weeks, but can't promise a response or fix time.

## Disclosure

Once a fix is on `main` (or it is clear none is coming), the report is
published as a GitHub security advisory, crediting you unless you'd rather not.
